        Rules overview

          Reference: docs/ROUTINES.md

          Android log

          Why the game closed: Android's crash reports and the log lines about the game, with its build and Android's free memory. Start the game, let it close, then press Show game log, Copy and paste it into your bug report.

          Device

          Apps

          Emulator stack: Install Dokkan (APKPure) installs the game's 32-bit ARM build, the one tested on the emulator (the Play Store may pick another one). With a phone install Dokkan from the Play Store. redroid stack: install Aurora Store, open it, log in anonymously and install Dragon Ball Z Dokkan Battle from there with Touch control on the Screen tab. You can also install an .apk, .xapk or .apks file.

          Behind Cloudflare an upload can be at most 100 MB: for bigger files open the farmer on its local address (http://server-ip:port) or install a link.

          Connect

          Network ADB address of your phone, emulator or redroid container, e.g. 192.168.1.50:5555 or redroid:5555.

          Pair (Android 11+ wireless debugging)

          1. On the phone: Developer options → Wireless debugging → Pair device with pairing code.
          2. Enter the IP address & port and the 6-digit code shown in that popup below.
          3. Then connect with the address shown on the Wireless debugging screen (a different port).
